# 饮品成分查询 · Drink Ingredient Check

> 把货架上每瓶饮料的成分表摊开来算分——添加糖、甜味剂、香精、防腐剂、色素、电解质、咖啡因逐项拆开，最后告诉你这一杯要不要留意。

**在线访问：<https://mayue-labs.github.io/drink-ingredient-check/>**

## 这是什么

一份自用的饮品成分手账，收录 **25 款**常见饮品，每款都按包装上的配料表与营养成分表给出百分制扣分评分（方法对齐「成分查查」类 App：添加糖为核心权重、双糖源加重、合规代糖从宽、电解质累积提醒、咖啡因人群提示），并附一句「对你来说要不要留意」的判断。

| 分类 | 数量 |
| --- | --- |
| 水 | 3 |
| 茶 | 6 |
| 咖啡 | 2 |
| 功能 | 4 |
| 电解质 | 4 |
| 汽水 | 6 |

## 评分规则

满分 100，逐项扣分后排序；同分时糖含量更低的排前面。锚点校准：东鹏补水啦电解质饮料在参考 App 为 72 分，本页同款同为 72 分。

| 维度 | 扣分方式 |
| --- | --- |
| 添加糖（核心） | 按每 100 mL 分档：0 g 不扣，≤4.5 g（低糖线）扣 8，≤8 g 扣 14，＞10 g 扣 19；白砂糖＋果葡糖浆「双糖源」再扣 2；整瓶折算＞25 g（膳食指南理想线）再扣 2 |
| 甜味剂 | 赤藓糖醇不扣；其他 1 种扣 2、2 种扣 4、3 种及以上扣 5 |
| 香精 | 扣 6 |
| 防腐剂 | 苯甲酸钠、山梨酸钾等，扣 4 |
| 人工色素 | 1 种扣 4、2 种及以上扣 5 |
| 其他添加剂 | 磷酸盐类扣 4、磷酸扣 2、EDTA 扣 3 |
| 电解质/钠 | 钠盐＋钾盐组合（电解质饮料）提醒与日常膳食累积，扣 4；仅含食用盐扣 2；钠＞60 mg/100 mL 扣 3 |
| 咖啡因 | 人群提示扣分：茶类扣 2，咖啡、可乐型扣 3，功能饮料扣 4 |

等级：≥90 推荐 / 75–89 适度推荐 / 60–74 一般推荐 / ＜60 不推荐。水质不参与扣分，仅作标签展示。判定依据：《中国居民膳食指南（2022）》、DRIs（2023）、GB 2760。糖量未标示的按品类估算并在页面标注「估算」。

## 功能

- 分类筛选（水 / 茶 / 咖啡 / 功能 / 电解质 / 汽水），带数量角标
- 模糊搜索，只匹配饮品名称
- 点击卡片展开配料表、营养成分、扣分明细与添加剂提示
- 饮品概览表：按评分排序，点某一行直接跳到对应卡片
- 评分规则说明弹窗，写清每一项是怎么扣的

## 技术

单文件 HTML，无构建、无依赖、无后端。样式、脚本、数据全部内联在 `index.html` 里，用浏览器直接打开就能用；数据以 JSON 数组形式放在脚本顶部，新增饮品只需往里加一条。

## 数据说明

数据来自包装上的配料表与营养成分表，多为拍照识读后转录；部分条目糖量、净含量或咖啡因含量尚未确认，按品类估算并在页面标注「估算」/「暂评」。评分是个人自用的粗筛工具，不构成营养或医疗建议。
