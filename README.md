# 成分查查 · Drink Ingredient Check

> 页面标题：饮品知多少。把货架上每瓶饮料的成分表摊开来算分——糖、钠、咖啡因、甜味剂、添加剂、水质逐项拆开，最后告诉你这一杯要不要留意。

**在线访问：<https://mayue-labs.github.io/drink-ingredient-check/>**

## 这是什么

一份自用的饮品成分手账，收录 **25 款**常见饮品，每款都按包装上的配料表与营养成分表给出六维评分，并附一句「对你来说要不要留意」的判断。

| 分类 | 数量 |
| --- | --- |
| 水 | 3 |
| 茶 | 6 |
| 咖啡 | 2 |
| 功能 | 4 |
| 电解质 | 4 |
| 汽水 | 6 |

## 评分规则

满分 100，逐项扣分后排序；同分时咖啡因更低的排前面。

| 维度 | 扣分方式 |
| --- | --- |
| 糖 | 按每 100 mL 糖含量分档：无糖 0 分起，超过 5 g 起扣 25 分 |
| 钠 | 含食用盐扣 5；含苯甲酸钠、柠檬酸钠、山梨酸钾等含钠添加剂再扣 3 |
| 咖啡因 | 低 / 中 / 高 三档，分别扣 5 / 10 / 15 |
| 甜味剂 | 1 种扣 5、2 种扣 10、3 种及以上扣 15 |
| 添加剂总数 | 防腐剂 + 色素 + 香精 + 酸度调节剂 + 二氧化碳，超 2 项起扣，最多 15 |
| 水质 | 矿泉水 0、纯净水 5、白开水 10 |

## 功能

- 分类筛选（水 / 茶 / 咖啡 / 功能 / 电解质 / 汽水），带数量角标
- 模糊搜索，只匹配饮品名称
- 点击卡片展开配料表、营养成分、扣分明细与添加剂提示
- 饮品概览表：按评分排序，点某一行直接跳到对应卡片
- 评分规则说明弹窗，写清每一项是怎么扣的

## 技术

单文件 HTML，无构建、无依赖、无后端。样式、脚本、数据全部内联在 `index.html` 里，用浏览器直接打开就能用；数据以 JSON 数组形式放在脚本顶部，新增饮品只需往里加一条。

## 数据说明

数据来自包装上的配料表与营养成分表，多为拍照识读后转录；部分条目品牌、净含量或咖啡因含量尚未确认，页面中标注为「暂评」。评分是个人自用的粗筛工具，不构成营养或医疗建议。
